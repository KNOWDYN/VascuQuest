# Exact axisymmetric kinematic lift

## Scope

`vascuquest.kinematics` reconstructs the axisymmetric velocity and vorticity fields implied by path-resolved VascuQuest/PWDB mean velocity and luminal-area signals.

The continuum reconstruction is exact under the declared source axioms. It is not CFD, FSI, a turbulence model, or an empirical wall-vorticity correlation.

The only numerical approximation introduced by the implementation is differentiation of discretely stored path samples with respect to physical path distance.

## Inputs

The canonical inputs are path-resolved source fields

```text
U(z,t)  cross-sectional mean axial velocity [m/s]
A(z,t)  luminal cross-sectional area [m^2]
z       physical path coordinate [m]
```

HEMOSPACE exposes the raw stored waveforms through `PathWaveField`. No hidden spatial interpolation, temporal resampling, or smoothing is performed.

The equivalent circular radius is

```text
R(z,t) = sqrt(A(z,t) / pi)
```

and must remain strictly positive.

## Source axioms

Version 1 requires:

- axisymmetric flow;
- zero swirl velocity;
- incompressible kinematics;
- a parabolic axial velocity profile whose cross-sectional mean is the supplied `U(z,t)`;
- a circular-equivalent lumen radius defined by `R=sqrt(A/pi)`.

The output is therefore the complete vorticity field of this axisymmetric no-swirl lifted model, not an unrestricted three-dimensional vorticity field.

## Exact velocity lift

The axial velocity is

```text
u_z(r,z,t) = 2 U(z,t) [1 - r^2/R(z,t)^2]
```

Incompressibility requires

```text
(1/r) d(r u_r)/dr + d(u_z)/dz = 0
```

and regularity at the axis removes the integration constant. The unique radial velocity is

```text
u_r = -r U_z
      + r^3 U_z/(2 R^2)
      - r^3 U R_z/R^3
```

with `u_theta = 0`.

At the wall,

```text
u_r(R) = -(R/2) U_z - U R_z
```

If the source fields satisfy the one-dimensional continuity equation

```text
A_t + (A U)_z = 0
```

then, identically,

```text
u_r(R) = R_t
```

so the radial fluid velocity matches the moving-wall velocity without an additional closure.

## Exact vorticity lift

For axisymmetric no-swirl flow,

```text
omega = (0, omega_theta, 0)
```

with

```text
omega_theta = d(u_r)/dz - d(u_z)/dr
```

Substitution gives

```text
omega_theta = 4 r U/R^2
              - r U_zz
              + r^3 U_zz/(2 R^2)
              - 2 r^3 R_z U_z/R^3
              - r^3 U R_zz/R^3
              + 3 r^3 U R_z^2/R^4
```

At the wall,

```text
omega_theta,w = 4 U/R
                - (R/2) U_zz
                - 2 R_z U_z
                - U R_zz
                + 3 U R_z^2/R
```

The implementation also exposes the decomposition

```text
omega_theta = -d(u_z)/dr + d(u_r)/dz
```

as the axial-shear contribution plus the radial-motion/path-variation contribution. The latter must not be described as the entire vorticity generated by wall motion: ordinary axial shear already produces nonzero azimuthal vorticity in a rigid tube.

## Numerical differentiation policy

`U_z`, `U_zz`, `R_z`, and `R_zz` are evaluated directly on the stored physical path coordinate using nonuniform finite differences. VascuQuest does not silently interpolate, resample, or smooth path signals.

When anatomical groups are supplied, differentiation is confined to contiguous groups. A group with fewer than three stored positions is inadmissible because the second spatial derivative required by the exact vorticity expression is not identifiable from that run.

Every result carries deterministic derivative-quality diagnostics including path spacing, minimum run length, spacing ratio, and warnings.

## Mathematical and numerical certificate

`certify_lift()` independently checks the returned discretized field through:

1. recovery of the supplied cross-sectional mean velocity;
2. axis regularity (`u_r=0`, `omega_theta=0`);
3. axial no-slip at the wall (`u_z(R)=0`);
4. an independently differentiated divergence check;
5. an independently differentiated curl check;
6. optionally, when a physical time vector is supplied, the source continuity residual and `u_r(R)=R_t` wall-motion identity.

The continuum identities are algebraic. The reported residuals quantify numerical differentiation/quadrature consistency only.

## Python API

```python
import vascuquest as vq

hs = vq.hemospace.open_hemospace(source="/path/to/pwdb", offline=True)
field = vq.kinematics.lift_hemospace_path(
    hs,
    "1",
    "aorta_foot",
    radial_points=17,
)
certificate = vq.kinematics.certify_lift(field)

wall_omega = field.wall_vorticity_s_1
omega = field.azimuthal_vorticity_s_1
u_r = field.radial_velocity_m_s
u_z = field.axial_velocity_m_s
```

Field arrays use dimensions

```text
(path_position, time, radial_fraction)
```

where `radial_fraction = r/R` runs from axis `0` to wall `1`.

For near-wall work without constructing a full radial field, use `wall_vorticity(U, A, z)`.

## CLI

```bash
vascuquest kinematics lift \
  --subject 1 \
  --path aorta_foot \
  --source /path/to/pwdb \
  --offline \
  --radial-points 17 \
  --output subject-1-aorta-foot-kinematics.npz
```

Run the certificate without exporting the full field:

```bash
vascuquest kinematics certify \
  --subject 1 \
  --path aorta_foot \
  --source /path/to/pwdb \
  --offline
```

If the stored-wave sample period is independently known, `--sample-period-s` enables the additional time-dependent continuity/wall-motion certificate.

## Evidence and interpretation

Kinematic-lift outputs are `DERIVED` from canonical source path waves. They do not become measured three-dimensional velocities or experimentally observed vorticity.

The correct claim is:

> exact axisymmetric kinematic reconstruction of the velocity and vorticity field implied by the source `U(z,t)`, `A(z,t)` variables and the declared parabolic/no-swirl/incompressible axioms.

The module does not claim unrestricted 3D vorticity, secondary-flow/swirl reconstruction, turbulence, wall shear stress validation, plaque mechanics, or fluid-solid interaction.
