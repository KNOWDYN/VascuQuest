THE PLATFORM

From a vascular population to a controlled experiment.

VascuQuest is built for questions that cannot be answered by a single idealised anatomy. It preserves each virtual subject while disease, mechanics, wave behaviour and statistical inference are layered on top.

DOWNSTREAM R&D
RESEARCH DOMAINS

Built around vascular questions that matter downstream.

The platform is strongest where population variability, disease severity and haemodynamic response must be separated cleanly before expensive device-specific or translational work begins.

01
CAROTID · STROKE

Controlled carotid disease across virtual populations.

Study how subject-level physiology and arterial state alter response to mechanistic common or internal carotid stenosis. Use NASCET-referenced severity where the disease model defines it, then quantify downstream haemodynamic consequences.

Carotid disease model ↗
02
ENDOVASCULAR R&D

Find the cases worth expensive device testing.

Use physiology and disease response to stratify virtual subjects before stent, flow-diverter, thrombectomy or other device-specific modelling is performed downstream.

Endovascular protocols ↗
03
VASCULAR MECHANICS

Interrogate pressure–area behaviour, not just pressure.

Compute compliance, distensibility, strain, stiffness, Bramwell–Hill wave-speed estimates and pressure–area loop quantities from aligned scientific objects.

04
WAVES · SPECTRA

Resolve haemodynamics in frequency and wave domains.

Harmonics, PSD/CSD, coherence, transfer functions, pressure–flow impedance, wave separation, reflection and wave-intensity workflows share one analysis contract.

SCIENTIFIC CONTRACT

Evidence should remain inspectable after analysis.

VascuQuest treats provenance as part of the scientific result. Dataset identity, subject or cohort, quantity meaning, units, vascular location, method, warnings and evidence state remain attached instead of disappearing into anonymous arrays.

ONE RESEARCH STACK

Population, disease, mechanics, waves, statistics and figures.

The research layer consumes native VascuQuest scientific objects. New analysis does not mutate the PWDB core, HEMOSPACE semantics or qualified Virtual Disease physics.

01

HEMOSPACE

Virtual cardiovascular records, cohort design, physiological derivations and knowledge closure.

02

VIRTUAL DISEASE

Carotid and iliac stenosis, abdominal aortic aneurysm and large-artery stiffening.

04

SPECTRAL

05

bash
# core
$ python -m pip install .

# complete research stack
$ python -m pip install ".[all]"

# inspect a cohort
$ vascuquest hemospace cohort ...

# quantify a result
$ vascuquest mechanics compute ...
$ vascuquest spectral impedance ...
$ vascuquest stats compare ...
